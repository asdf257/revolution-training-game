# 革命学堂 · 抗日根据地养成游戏

一款以陕北公学为背景的网页养成游戏。玩家扮演 1938 年来到抗日根据地革命学校的青年，通过 8 周选课、上课、测验与课余活动，提升政治素养、军事能力、劳动技能与群众工作等属性，体验历史氛围下的学习与成长。



## 如何运行

- **直接打开**：用浏览器打开项目根目录下的 `index.html` 即可运行。
- **本地服务器（推荐）**：若遇跨域或资源加载问题，可用任意静态服务器，例如：
  ```bash
  # 若已安装 Node.js
  npx serve .
  # 或
  npx http-server .
  ```
  然后访问终端提示的地址。

无需安装依赖或构建，纯前端项目。

## 主要玩法

- **选课**：每周从政治、军事、劳动、群众工作四类课程及课余活动中选 5 项，部分课程有先修与周数限制。
- **每日课程**：按周一到周五依次进行，包含课程导论、课堂互动（视觉小说式点击推进与选择）、测验（若该课需结业）。
- **课堂互动**：点击逐段推进剧情，遇到选项时弹出选择框（AB 选择带 10 秒倒计时，测验题无倒计时），结果与结尾文字按设定展示。
- **小游戏**：部分军事课程附带小游戏（如吃豆人、消消乐等），完成可获得额外属性加成。
- **周结算**：周末结算属性与健康值，可触发随机事件或医院剧情，共 8 周后根据属性进入不同结局。
